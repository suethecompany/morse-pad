MORSE PAD
=========

Put all files in this folder on any static web host (HTTPS). Open the address on the phone,
then add it to the home screen:

  iPhone:  Safari > Share (or ••• > Share) > Add to Home Screen
  Android: Chrome > ⋮ menu > Add to Home screen / Install app

After the first visit it works offline. When you change a file, also change VERSION at the
top of sw.js (for example morse-pad-v2) so phones pick up the new version. It arrives the
second time the app is opened after the update.
